# v1.3.0 Release Notes — DeepSeek Harness 适配与卡组技能学习机制

本版本主要适配 DeepSeek Harness (DSH) `0.1.7-rc.2` 运行时体系，将“游戏王模式”迁移至新版 bundle 预设架构，并新增基于 YRP 决斗录像的卡组操作提取与上下文技能（Skill）固化机制。

---

## 核心更新

### 1. 游戏王模式预设重构与 Bundle 架构迁移
- **Bundle 预设分发**：预设注册机制迁移至 DSH 推荐的 bundle 体系并随插件包内置分发，废弃原有基于 `.agent-presets/ygoai` 的文件注册路径。
- **基线能力集成**：安装插件后，Web 界面在新建会话时即可直接选用“游戏王模式”。该模式在 DSH 0.1.7-rc.2 标准能力基线上，叠加注入专属游戏王工具链。

### 2. 卡组录像学习与 Skill 上下文动态注入（`learnDeck`）
工具集总数由 14 项扩充至 15 项，新增 `learnDeck` 工具，为模型引入自动化卡组经验归纳与复用能力：
- **操作提取与策略复盘**：从 YRP 决斗录像中提取可见操作流，由模型结合对局复盘提炼策略要点（`strategyNotes`），并持久化为与卡组强绑定的 Markdown Skill 文件。
- **系统边界与定位**：本方案属于“外部持久化 Skill 存储与动态会话上下文检索注入”，不改动模型底层权重；录像提取的操作与模型总结提供策略指导，实际对局仍以运行时生成的合法动作集为准进行动态核验。若录像解析中断或不完整，系统将明确标注为仅覆盖前缀操作。
- **卡组指纹与精准匹配**：卡组指纹覆盖主卡组（Main）、额外卡组（Extra）与副卡组（Side），采用多重集比对（忽略构筑排列顺序，严格保留同名卡数量）。卡表调整将自动切断旧 Skill 匹配；当 YRP 录像未包含副卡组数据时，支持降级绑定主卡组与额外卡组完全一致的当前会话卡组。
- **全生命周期管理**：`learnDeck` 提供学习（`learn`）、检索（`list`）、查看（`get`）、激活（`activate`）及删除（`delete`）五项核心操作，策略复盘支持二次更新保存；覆盖存量记录与物理删除必须显式传入对应参数。

## 运行时与架构改进

### 1. 结构化工具通信
- 工具返回格式全面迁移为结构化对象，原生兼容直接工具调用与 PTC（Programmatic Tool Calling，程序化工具调用）。

### 2. 容器生命周期与会话强隔离
- 工具与技能的注册、释放全程交由 Cordis 容器生命周期管理，支持整洁的热卸载与资源回收。
- 运行时严格依赖 DSH `session id` 进行多会话隔离；未携带会话标识的调用将被拒绝路由，杜绝共享默认上下文导致的状态污染。

### 3. 超时与取消信号穿透（AbortSignal）
- 取消信号与超时时间直通外部决斗引擎客户端，触发取消时立即中止本地等待队列与网络请求；已交给独立引擎的操作不保证取消或回滚。

## 安装与升级指引

### 安装命令

```powershell
dsh plugin --profile web add "https://github.com/mellfy-puppy/ygo-tools-for-dsh/releases/download/v1.3.0/ygo-tools-for-dsh-1.3.0.tgz"
```

### 迁移与配置说明
- **预设刷新**：若 Web 端未显示新预设，重启 DSH 后新建会话并选择“游戏王模式”即可。升级前已经开始的会话保留原有预设绑定。
- **运行环境要求**：Node.js >= 22（推荐验证环境：DSH 0.1.7-rc.2 + Node.js 24.19.0）。
- **技能存储路径**：Skill 默认持久化保存在 `$DSH_HOME/ygo-tools-for-dsh/deck-skills`，可通过插件配置参数 `deckSkillDir` 或环境变量 `YGO_DECK_SKILL_DIR` 灵活重定向。
- **开箱即用**：安装包已全量内置核心决斗引擎、卡片数据库与运行脚本资源，可选 YGOPro2 桥接仍需外部客户端。
